# Implemented method controls

This table records behavior from the implementation, not from method names. “IF” is
InterFuser and “TF” is TransFuser. IF quality inputs are per-modality pre-fusion feature
mean/std/norm statistics plus raw camera intensity/sharpness and LiDAR occupancy cues
([`rrf/gated.py:66`](../rrf/gated.py#L66), [`rrf/gated.py:87`](../rrf/gated.py#L87)); TF uses
the corresponding first-stage feature statistics and raw cues
([`rrf/tf_gated.py:44`](../rrf/tf_gated.py#L44), [`rrf/tf_gated.py:63`](../rrf/tf_gated.py#L63)).
Both estimators concatenate the two modality rows and four availability flags, normalize by
fixed `mu`/`sigma`, and end in a sigmoid
([`rrf/gated.py:108`](../rrf/gated.py#L108), [`rrf/gated.py:129`](../rrf/gated.py#L129)).

TransFuser stage-level removal masks tokens/features at all four fusion stages; because a
stage intervention does not rewind the retained branch, that branch can retain information
fused at an earlier boundary. Sensor-level removal instead supplies the encoders with a black
camera frame or empty LiDAR BEV ([`rrf/tf_gated.py:249`](../rrf/tf_gated.py#L249),
[`rrf/tf_gated.py:258`](../rrf/tf_gated.py#L258)).
